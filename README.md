# PEAN的开发小天地

**V2.0.0-New liquid Pro**

Windows 桌面学习软件：iOS 风格液态玻璃界面，加上一个陪你学习、督促你打卡的 AI 教练。基于 Electron + 原生 HTML/CSS/JS，没有构建步骤。

## 功能

- **伴学首页**：AI 状态球、陪学计时、持续对话，学习时走神会被提醒
- **每日计划**：和教练商量今天或明天做什么
- **AI 审核打卡**（可选）：对照计划和证据判断，没达标写理由，驳回就不能打卡；断网先打卡，联网后补审
- **激励**：连续天数、火焰、奖章墙
- **人生路线**：阶段和任务随时增删，AI 帮忙调整和拆解
- **记录**：日历、心情、Markdown 日记、截图、热力图、周复盘
- **外观**：液态玻璃、弹簧动效、动态或自选壁纸，深浅色主题

## AI 和隐私

AI 使用你自己的 DeepSeek API Key，Key 由系统加密保存，不进备份。发给 DeepSeek 的内容：计划和进度、监控文件夹里的文件名、自己的 git 提交说明、开发软件时长、日记字数和截图数量。日记正文和心情在设置里单独开关。文件内容、窗口标题和其他软件的名字都不会发送。AI 不能操作你的电脑。

## 运行

```bash
npm install
npm start        # 启动软件
npm run lab      # 打开液态玻璃 / 动效原型实验室
npm run orb      # 打开 AI 状态图标实验页
npm test         # 运行规则与数据模型单元测试
npm run verify -- <data目录>   # 在数据副本上核对迁移前后的关键数字
npm run install-local -- --close   # 备份数据后安装到本机并启动
npm run build    # 打包 Windows 安装程序
```

用户数据保存在本机 `%APPDATA%\learning-dashboard\data\`，不在仓库里。
